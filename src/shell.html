PCB 焊接导航

拖入 PCB 工程或生产文件，按焊接顺序列出器件、在板图上标出位置和方向，也能逐脚查网络做通断测试。支持 KiCad、嘉立创EDA、Altium、Cadence Allegro、ODB++ 和 Gerber。文件只在你的浏览器里解析，不会上传。

把工程文件夹拖到这里

文件夹、zip、单个文件都行。里面有几块板就读出几块；同目录的 BOM、坐标文件、网表会自动配上。

能读的文件

KiCad.kicad_pcb（6 ~ 10）
嘉立创EDA 专业版工程 .epro / .epro2 / 备份 .epru；或 Gerber 包（带飞针文件）
Altium Designer.PcbDoc；或 IPC-2581 / ODB++ / Gerber + Pick Place
Cadence Allegro / OrCAD导出的 IPC-2581（File → Export → IPC 2581）；或 Gerber(.art) + 坐标 + IPC-356。.brd 原文件是加密格式，读不了
PADS / 其他IPC-2581、ODB++，或 Gerber + 坐标文件

文件组合说明

  • 设计文件（KiCad / 嘉立创 / Altium / IPC-2581 / ODB++）信息最全：焊盘、引脚号、网络都有
  • 只有 Gerber 时，需要配上坐标文件（Pick and Place / CPL）才能知道器件；再配上 IPC-356 网表或嘉立创飞针文件，就能查引脚和网络
  • BOM 可以是 CSV 或 Excel（.xlsx），用 Comment / LCSC 列补全名称和料号

读进来以后

  • 按焊接顺序分步：细间距芯片 → 小封装 → 阻容 → 有极性件 → 大件 → 开关 → 底面 → 插件
  • 标出 1 脚、二极管阴极、电解/钽电容正极，并用文字说出朝哪边
  • “测引脚”：点任意焊盘看是哪个器件第几脚、接什么网络、和哪些点应导通
  • 勾选进度和读入的板子保存在本机浏览器，下次打开还在

测试点与引脚

点板上任意焊盘：卡片显示它是哪个器件第几脚、接哪个网络，同网络的其他焊盘标成紫色。万用表通断档一支表笔放在选中焊盘，另一支放任一紫色焊盘应导通。

快捷键：N 下一种　[ 上一种　空格 焊完这种　T 焊接/测引脚　F 翻面　D 双面对照　R 旋转　0 全板　Esc 清除

极性按常见封装库惯例（KiCad、立创、Altium）判断：二极管、LED 的 1 号焊盘是阴极，电解/钽电容、电池的 1 号焊盘是正极。少数厂家封装不同，焊之前对一下丝印。

所有文件只在这台设备的浏览器里解析和保存，不上传任何服务器。
